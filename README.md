# CalcSprint

Static fast-calculation trainer for GitHub Pages.

## Features

- Dark-mode-first interface with `#99eedd` accents
- Addition, subtraction, and mixed operation rounds
- Flash-speed slider from 0.20s to 2.00s
- Custom number range input, such as `100000-1000000`
- Accountancy mode for `10,000` to `1,000,000` with last three digits of `000`, `250`, `500`, or `750`
- Ready / Set / Go countdown before flashing begins
- Replay the exact same round, skip to results, or check an answer
- Results screen with the full calculation and correct total

## Hosting

This is plain HTML, CSS, and JavaScript. Host the repository root with GitHub Pages, or open `index.html` directly in a browser.
